## 1. 系统概述

### 1.1 系统简介

Template System 是一款**文档解析与样式预览系统**，用于对 Word（.docx）文档进行内容识别、样式校验和格式化导出。系统通过预定义的规则和正则表达式，自动识别文档中的封面、目录、标题、正文等段落类型，并以 PDF 高亮预览的方式直观展示识别效果。

**核心能力**：

```
上传 Word 文档 → 内容识别解析 → PDF 高亮预览 → 段落样式调整 → 导出格式化文件
```

### 1.2 核心概念

| 概念 | 说明 | 示例 |
|------|------|------|
| **模板** | 一组规则和引擎配置的集合，代表一种文档格式规范 | "本科论文模板""招标文件模板" |
| **规则** | 定义段落的样式属性（字体、大小、颜色、对齐等） | "一级标题：黑体 16pt 加粗 居中" |
| **引擎配置** | 正则表达式 + 匹配类型 + 关联规则，决定"哪些段落属于哪种类型" | "匹配'第X章'的段落 → 标记为TITLE → 应用一级标题规则" |
| **段落匹配** | 引擎配置作用于文档段落的匹配结果 | "第一章 绪论 → TITLE(1级) → 一级标题样式" |

**概念关系图**：

```
┌──────────┐     包含     ┌──────────────┐     包含     ┌──────────┐
│   模板    │ ─────────→  │   引擎配置     │ ─────────→  │   规则    │
│ Template │              │ EngineConfig  │   关联规则   │  Rule    │
└──────────┘              └──────────────┘              └──────────┘
     │                          │
     │ 关联                     │ 匹配段落
     ▼                          ▼
┌──────────┐              ┌──────────────┐
│ 上传文件  │   解析生成    │  段落匹配结果  │
│  File    │ ───────────→ │ ParagraphMatch│
└──────────┘              └──────────────┘
```

### 1.3 技术环境

| 项目 | 要求 |
|------|------|
| 浏览器 | Chrome 90+ / Edge 90+（推荐最新版） |
| 网络 | 能访问系统部署服务器 |
| 屏幕分辨率 | 推荐 1920×1080 及以上 |

系统采用左侧导航 + 右侧内容区的经典布局。

## 2. 快速入门

### 2.1 访问系统

1. 打开 Chrome 或 Edge 浏览器
2. 在地址栏输入系统地址（如 `http://localhost:3000`），按回车
3. 确认页面正常加载，显示「模板列表」页面

### 2.2 三步快速体验

以下通过最简操作体验系统核心功能：

**第一步：创建模板**

1. 在模板列表页，点击右上角 **「新建模板」** 按钮
2. 在弹出的对话框中输入模板名称，如 `测试模板`
3. 点击 **「确定」**

> 模板创建成功，列表中显示新模板，状态为「启用」。

**[截图：新建模板对话框]**

**第二步：上传文件并解析**

1. 点击左侧导航 **「文件上传」**
2. 在「关联模板」下拉框中选择刚创建的 `测试模板`
3. 将 .docx 文件拖拽到上传区域，或点击选择文件
4. 点击 **「开始上传」**
5. 上传成功后，在文件列表中找到该文件，点击 **「解析」**

> 解析成功后，文件状态变为「已解析」（绿色标签）。

**[截图：文件上传页面 — 拖拽区域 + 关联模板下拉]**

**第三步：预览结果**

1. 在文件列表中，点击该文件的 **「预览」** 按钮
2. 进入解析预览页，左侧显示 PDF 渲染结果
3. 右侧面板显示样式图例和段落列表
4. 使用翻页控件浏览 PDF 各页

> 如果模板下没有配置引擎规则，所有段落将标记为 UNKNOWN（红色标签）。

**[截图：解析预览页面全貌]**

## 3. 模板管理

### 3.1 模板列表页

模板列表页是系统的默认首页，展示所有已创建的模板。

**表格列说明**：

| 列名 | 说明 |
|------|------|
| ID | 模板唯一编号，系统自动生成 |
| 模板名称 | 创建时填写的名称 |
| 状态 | 启用（绿色）/ 禁用（灰色） |
| 创建时间 | 模板创建的时间戳 |

**页面功能**：
- 右上角 **「新建模板」** 按钮
- 每行操作列：**「编辑」** 和 **「启用/禁用」**
- 底部分页控件：可切换每页显示 10/20/50 条

**[截图：模板列表页 — 标注表格列和操作按钮]**

### 3.2 新建模板

1. 在模板列表页，点击 **「新建模板」**
2. 在弹出对话框中输入模板名称
   - 名称不能为空
   - 建议使用有意义的名称，如 `本科论文模板`、`招标文件模板`
3. 点击 **「确定」**
4. 模板创建成功，列表中新增一条记录，状态默认为「启用」

**[截图：新建模板对话框，标注名称输入框和确定按钮]**

### 3.3 编辑模板

1. 在模板列表中找到目标模板，点击 **「编辑」**
2. 进入模板详情页，显示「基本信息」和「规则列表」两个卡片
3. 在基本信息卡片中修改模板名称
4. 点击 **「保存」**

> 模板详情页同时也是规则管理页面，详见[第 4 章](#4-样式规则配置)。

**[截图：模板详情页 — 基本信息区域]**

### 3.4 启用/禁用模板

1. 在模板列表页，点击目标模板行的 **「启用」** 或 **「禁用」** 按钮
2. 状态立即切换，无需确认

| 操作 | 效果 |
|------|------|
| 点击「禁用」 | 模板状态变为禁用（灰色），关联文件执行解析时将报错"模板不存在或已停用" |
| 点击「启用」 | 模板状态变为启用（绿色），恢复正常使用 |

> **注意**：禁用模板不会删除已有数据，仅阻止新的解析操作。

### 3.5 删除模板

当前版本前端未提供模板删除入口。如需删除模板，请联系系统管理员在数据库中操作。

> 删除模板前，请确认没有文件仍关联该模板，否则文件将无法正常解析。

## 4. 样式规则配置

### 4.1 规则列表

进入方式：模板列表页 → 点击模板的「编辑」→ 在详情页下方找到「规则列表」卡片。

**表格列说明**：

| 列名 | 说明 |
|------|------|
| ID | 规则唯一编号 |
| 规则名称 | 如"一级标题""正文" |
| 字体 | 设置的字体名称，如"宋体" |
| 字号 | 设置的磅值，如 16 |
| 加粗 | 是/否/-（未设置显示"-"） |
| 斜体 | 是/否/- |

**[截图：规则列表卡片]**

### 4.2 新增规则

1. 在规则列表卡片右上角，点击 **「新增规则」**
2. 在弹出的对话框中填写规则信息（字段说明见下表）
3. 点击 **「确定」**

### 4.3 编辑规则

1. 在规则列表中，点击目标规则行的 **「编辑」**
2. 在弹出对话框中修改需要变更的字段
3. 点击 **「确定」**

### 4.4 删除规则

1. 在规则列表中，点击目标规则行的 **「删除」**
2. 在确认弹窗中点击 **「确定」**

> **注意**：删除规则后，引擎配置中关联该规则的配置将失去样式引用，导出时该段落不会应用任何样式。

### 4.5 规则字段完整参考

**[截图：规则编辑对话框 — 标注各字段位置]**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| **规则名称** | 文本输入 | **是** | 规则的标识名称。建议使用有意义的名称，如"一级标题""二级标题""正文""封面标题" |
| **字体名称** | 文本输入 | 否 | 中文字体或英文字体名称。如"宋体""黑体""楷体""Times New Roman" |
| **字号(磅)** | 数字输入 | 否 | Word 磅值单位。常用值：三号=16、四号=14、小四=12、五号=10.5 |
| **加粗** | 开关 | 否 | 开启后文字加粗显示 |
| **斜体** | 开关 | 否 | 开启后文字倾斜显示 |
| **下划线** | 开关 | 否 | 开启后文字添加下划线 |
| **删除线** | 开关 | 否 | 开启后文字添加删除线 |
| **字体颜色** | 颜色选择器 | 否 | 点击色块挑选颜色，或直接输入十六进制值（如 #FF0000） |
| **文本对齐** | 下拉选择 | 否 | 可选：左对齐 / 居中 / 右对齐 / 两端对齐 |
| **首行缩进(字符)** | 数字输入 | 否 | 段落首行缩进的字符数。中文正文通常设为 2 |
| **行距(倍)** | 数字输入 | 否 | 行间距倍数。如 1.5 倍行距输入 1.5 |
| **段前距(磅)** | 数字输入 | 否 | 段落前的空白间距（磅） |
| **段后距(磅)** | 数字输入 | 否 | 段落后的空白间距（磅） |
| **高亮颜色** | 颜色选择器 | 否 | PDF 预览中该规则段落的底色。**不设置则系统自动按规则 ID 生成颜色** |

> **提示**：规则中的字段仅在**导出**时应用到 Word 文档。PDF 预览中的高亮颜色由「高亮颜色」字段控制，与字体颜色无关。

## 5. 内容识别引擎配置

### 5.1 引擎配置概述

引擎配置是系统的核心，它定义了**哪些段落文字应当被识别为哪种类型，并关联哪种样式规则**。

每条引擎配置由三要素组成：

```
正则表达式 + 匹配类型 + 关联规则 = 一条引擎配置
```

**工作流程**：

1. 系统逐段读取 Word 文档的段落文本
2. 按优先级（SPECIAL → COVER → TOC → TITLE → BODY）遍历引擎配置
3. 用配置中的正则表达式匹配段落文本
4. 首个匹配成功的配置决定该段落的类型和规则
5. 匹配失败则标记为 UNKNOWN

### 5.2 匹配类型与优先级

系统支持 5 种匹配类型，按优先级从高到低排列：

| 优先级 | 类型 | 标签颜色 | 用途 | 创建方式 |
|--------|------|---------|------|---------|
| 1（最高） | **SPECIAL** | 灰色 | 特殊段落精确匹配 | 预览页调整 UNKNOWN 段落时自动创建 |
| 2 | **COVER** | 橙色 | 封面内容（论文题目、作者等） | 手动创建 |
| 3 | **TOC** | 蓝色 | 目录行（含省略号和页码） | 手动创建 |
| 4 | **TITLE** | 蓝色 | 标题（支持 1-9 级） | 手动创建 |
| 5（最低） | **BODY** | 绿色 | 正文段落 | 手动创建 |

> **重要**：同一段落只会匹配**优先级最高**且**正则匹配成功**的配置。例如，段落"第一章 绪论"同时被 TITLE 和 BODY 的配置匹配时，因为 TITLE 优先级更高，将被标记为 TITLE。

### 5.3 进入引擎配置页

有两种方式：

- **方式一**：左侧导航 → 点击「引擎配置」
- **方式二**：模板详情页 → 点击顶部「引擎配置」按钮

### 5.4 选择模板

在引擎配置页顶部，使用 **「选择模板」** 下拉框选择要配置的模板。

- 下拉框列出所有已创建的模板
- 从模板详情页跳转时，会自动选中对应模板
- 切换模板后，配置列表自动刷新

**[截图：引擎配置页 — 选择模板下拉框 + 配置列表]**

### 5.5 新增引擎配置

1. 确保已选择目标模板
2. 点击 **「新增配置」**
3. 填写配置表单（字段说明见下表）
4. 点击 **「确定」**

### 5.6 编辑引擎配置

1. 在配置列表中，点击目标配置行的 **「编辑」**
2. 修改需要变更的字段
3. 点击 **「确定」**

### 5.7 删除引擎配置

1. 在配置列表中，点击目标配置行的 **「删除」**
2. 在确认弹窗中点击 **「确定」**

### 5.8 引擎配置字段完整参考

**[截图：引擎配置编辑对话框 — 标注各字段]**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| **配置名称** | 文本输入 | **是** | 配置的标识名称，如"封面匹配""一级标题匹配" |
| **正则表达式** | 文本域 | **是** | Java 正则表达式语法。用于匹配段落文本，详见[附录 9.2](#92-正则表达式常用示例) |
| **匹配类型** | 下拉选择 | **是** | COVER / TOC / TITLE / BODY（SPECIAL 由系统自动创建） |
| **标题级别** | 数字输入 | TITLE 时可选 | 1-9 的整数。仅在匹配类型为 TITLE 时显示，如一级标题填 1 |
| **关联样式** | 下拉选择 | 否 | 关联当前模板下的规则。匹配成功后，该段落将应用对应规则的样式 |
| **排序序号** | 数字输入 | **是** | 同类型内的匹配顺序。序号越小越优先匹配，默认值为 1 |
| **启用状态** | 开关 | **是** | 停用的配置不参与段落匹配 |

### 5.9 引擎配置策略建议

**基础配置（覆盖大部分场景）**：

| 配置名称 | 匹配类型 | 正则表达式 | 关联规则 |
|---------|---------|-----------|---------|
| 封面匹配 | COVER | `论文题目\|作者\|指导老师\|学院\|专业` | 封面样式 |
| 目录匹配 | TOC | `^.+\s*\.{2,}\s*\d+$` | 目录样式 |
| 一级标题 | TITLE(1) | `^第[一二三四五六七八九十]+章` | 一级标题样式 |
| 二级标题 | TITLE(2) | `^\d+\.\d+\s+` | 二级标题样式 |
| 正文匹配 | BODY | `.*` | 正文样式 |

> **BODY 配置建议放在最后**：BODY 的 `.*` 会匹配所有段落，因此它应作为兜底配置，确保其他类型的更高优先级配置先被尝试。

## 6. 文件管理

### 6.1 文件上传

**操作步骤**：

1. 点击左侧导航 **「文件上传」**
2. （可选）在「关联模板」下拉框中选择模板。如果不选，后续解析前需要通过「修改」按钮关联
3. 将 .docx 文件拖拽到虚线区域，或点击区域选择文件
4. 确认文件名出现在上传区域后，点击 **「开始上传」**
5. 上传成功后，文件出现在下方列表中，状态为 UPLOADED

**支持的文件格式**：

| 格式 | 支持 | 说明 |
|------|------|------|
| .docx | 是 | Word 2007 及以上版本的默认格式 |
| .doc | 否 | 旧版 Word 格式，请先用 Word 另存为 .docx |

**文件大小限制**：默认最大 50MB。如需调整，请联系管理员修改配置。

**[截图：文件上传页 — 拖拽区域 + 关联模板下拉]**

### 6.2 文件列表与操作

文件列表展示所有已上传的文件，每行提供 6 个操作按钮。

**表格列说明**：

| 列名 | 说明 |
|------|------|
| 文件名 | 上传时的原始文件名 |
| 大小 | 文件大小（自动格式化为 B/KB/MB） |
| 关联模板 | 文件关联的模板名称，未关联则显示为空 |
| 状态 | 见下方状态说明 |
| 上传时间 | 文件上传的时间戳 |

**文件状态说明**：

| 状态 | 标签颜色 | 含义 | 可执行操作 |
|------|---------|------|-----------|
| UPLOADED | 蓝色 | 已上传，尚未解析 | 解析、预览、修改、删除 |
| PARSED | 绿色 | 解析成功，可预览和导出 | 解析、预览、导出、下载、修改、删除 |
| ADJUSTED | 橙色 | 已完成段落-规则调整 | 解析、预览、导出、下载、修改、删除 |
| EXPORTED | 灰色 | 已导出格式化文件 | 预览、导出、下载、修改、删除 |
| PARSE_FAILED | 红色 | 解析失败 | 修改、删除（检查错误原因后重新解析） |

**状态流转图**：

```
UPLOADED ──解析──→ PARSED ──调整──→ ADJUSTED ──导出──→ EXPORTED
    │                 │                  │                  │
    └──解析失败────→ PARSE_FAILED       │                  │
                                        └────导出────→ EXPORTED
```

**操作按钮说明**：

| 按钮 | 颜色 | 前置条件 | 功能说明 |
|------|------|---------|---------|
| **解析** | 蓝色 | 文件已关联模板 | 启动内容识别引擎，逐段匹配并生成解析结果。模板必须为启用状态 |
| **预览** | 绿色 | 文件已解析 | 进入 PDF 预览页，查看高亮标注和段落匹配结果 |
| **导出** | 橙色 | 文件已解析/已调整/已导出 | 将规则中定义的样式应用到 Word 文档，生成格式化文件 |
| **下载** | 灰色 | 文件已导出 | 下载格式化后的 .docx 文件到本地 |
| **修改** | 灰色 | 任意状态 | 更改文件关联的模板。注意：更换模板后需重新解析 |
| **删除** | 红色 | 任意状态 | 删除文件及所有关联数据（**不可恢复**） |

#### 6.4.4 段落调整

右侧面板下半部分是**段落调整区**，列出文档中每个段落的匹配结果。点击段落头部可展开调整面板。

**段落头部信息**：

| 元素 | 说明 |
|------|------|
| #序号 | 段落在文档中的位置（从 1 开始） |
| 类型标签 | 当前匹配类型，UNKNOWN 为红色表示未匹配 |
| 文本预览 | 段落前 60 字符的样式预览（显示字体、大小、加粗/斜体等实际效果） |

**调整操作**：

1. 在段落列表中，点击目标段落展开调整面板
2. 从「选择样式规则」下拉框中选择正确的规则
3. 调整后的规则名称立即更新
4. 点击顶栏 **「保存调整」** 按钮提交所有修改

**[截图：段落调整 — 展开状态，标注规则下拉框]**

**调整行为说明**：

| 原匹配类型 | 调整后 | 系统行为 |
|-----------|--------|---------|
| UNKNOWN | 选择规则 | 自动创建 SPECIAL 类型引擎配置，下次解析同样文本自动匹配 |
| 其他类型 | 更换规则 | 更新段落关联的 ruleId |

> **提示**：UNKNOWN 段落调整后，系统会自动为该段落的精确文本创建 SPECIAL 配置（优先级最高），确保后续文件解析时该段落能被正确识别。

#### 6.4.5 保存调整

1. 完成所有段落调整后，点击顶栏 **「保存调整」** 按钮
2. 按钮在有效调整前为禁用状态（灰色），修改任何段落规则后变为可用（蓝色）
3. 保存成功后页面自动刷新，PDF 高亮同步更新

> **注意**：「保存调整」按钮仅在做了修改后可用。如果只是查看未改动，无需点击保存。

### 6.5 导出与下载

#### 导出

导出将规则中定义的样式**实际应用**到 Word 文档的段落后生成新文件。

1. 在文件列表中，点击目标文件的 **「导出」** 按钮
2. 系统自动应用规则样式到各段落，生成格式化文件
3. 导出成功后，文件状态变为 EXPORTED，同时生成输出文件名

**导出的样式范围**：

| 规则字段 | 是否导出 | 说明 |
|---------|---------|------|
| 字体名称 | 是 | 应用到段落所有 Run |
| 字号 | 是 | 应用到段落所有 Run |
| 加粗/斜体/下划线/删除线 | 是 | 应用到段落所有 Run |
| 字体颜色 | 是 | 应用到段落所有 Run |
| 文本对齐 | 是 | 应用到段落级别 |
| 首行缩进 | 是 | 应用到段落级别 |
| 行距 | 是 | 应用到段落级别 |
| 段前距/段后距 | 是 | 应用到段落级别 |
| 高亮颜色 | **否** | 仅在 PDF 预览中使用 |

#### 下载

1. 确认文件已导出（状态为 EXPORTED）
2. 点击 **「下载」** 按钮
3. 浏览器自动下载文件，文件名格式为 `原文件名_格式化.docx`

> 如果下载的文件名包含特殊字符，浏览器会自动进行 URL 编码处理。

### 6.6 删除文件

1. 在文件列表中，点击目标文件的 **「删除」** 按钮
2. 在确认弹窗中核对文件名，点击 **「确定」**
3. 文件及所有关联的解析数据、导出数据将被**永久删除**

> **警告**：删除操作不可恢复。请确认文件不再需要后再执行删除。

## 8. 常见问题与故障处理

### 8.1 文件上传

**Q：上传时提示"仅支持 .docx 格式文件"？**

- 原因：文件扩展名不是 .docx
- 解决：用 Microsoft Word 或 WPS 打开文件，另存为 .docx 格式（Word 2007+ 默认格式）

**Q：上传失败，没有任何提示？**

- 原因：文件大小超过 50MB 限制
- 解决：压缩文件中的图片，或联系管理员调整 `spring.servlet.multipart.max-file-size` 配置

### 8.2 文件解析

**Q：解析失败："未指定解析模板"？**

- 原因：文件上传时未关联模板
- 解决：点击文件的「修改」按钮，选择模板后重新解析

**Q：解析失败："模板不存在或已停用"？**

- 原因：关联的模板已被禁用
- 解决：到模板列表页找到该模板，点击「启用」

**Q：解析后所有段落都是 UNKNOWN？**

- 原因：模板下没有配置引擎规则，或正则表达式均不匹配
- 解决：进入引擎配置页，为该模板创建匹配规则（至少需要一条 BODY 兜底配置）

### 8.3 PDF 预览

**Q：PDF 预览区一片空白？**

- 原因：中文字体（SimHei 黑体）未正确安装或路径配置错误
- 解决：联系管理员检查服务器字体安装和 `application.yml` 中 `template.pdf.font.path` 配置

**Q：PDF 高亮位置偏移，和实际文字对不上？**

- 原因：PDF 文本提取的字符计数与 Word 原文存在偏差
- 解决：点击「保存调整」触发重新计算；如仍偏移，联系管理员检查 PDF 转换配置

**Q：PDF 翻页很慢？**

- 原因：文档页数较多，每页渲染需要时间
- 解决：等待渲染完成再操作，避免快速连续翻页

### 8.4 导出下载

**Q：导出失败？**

- 原因：文件尚未解析，或解析数据损坏
- 解决：先执行解析，确认状态为 PARSED 后再导出

**Q：下载的文件样式没有变化？**

- 原因1：规则中的字段都为空 — 至少设置一个样式字段
- 原因2：引擎配置未正确关联规则 — 检查配置的「关联样式」字段
- 原因3：段落匹配类型为 UNKNOWN — 在预览页调整后重新导出

### 8.5 其他问题

**Q：页面加载不出来，一直转圈？**

- 原因：后端服务未启动或网络不通
- 解决：
  1. 确认后端服务（端口 8080）是否正常运行
  2. 确认前端开发服务器（端口 3000）是否正常运行
  3. 检查浏览器控制台（F12 → Console）是否有网络错误

**Q：操作后数据没有刷新？**

- 原因：部分操作完成后需手动刷新列表
- 解决：大多数操作（创建、上传、解析、导出）会自动刷新列表。如未自动刷新，手动点击浏览器的刷新按钮（F5）

### 9.2 正则表达式常用示例

| 场景 | 正则表达式 | 匹配示例 |
|------|-----------|---------|
| 精确匹配"摘要" | `^摘要$` | `摘要`（仅此一词） |

| 匹配关键词（多个） | `摘要\|Abstract\|关键词\|Keywords` | 包含任一关键词的段落 |
| 匹配"X、标题"格式 | `^[一二三四五六七八九十]、` | `一、`、`三、` |
| 匹配参考文献标题 | `^参考文献$` | `参考文献` |
| 匹配所有非空段落（兜底） | `.+` | 任意非空文本 |

> **提示**：`^` 表示行首，`$` 表示行尾，`\|` 表示"或"，`.*` 表示任意字符任意次数，`\d` 表示数字，`\s` 表示空白字符。

### 9.3 文件状态完整定义

| 状态值 | 标签颜色 | 含义 | 触发条件 |
|--------|---------|------|---------|
| `UPLOADED` | 蓝色 | 已上传 | 文件上传成功 |
| `PARSED` | 绿色 | 已解析 | 内容识别完成 |
| `ADJUSTED` | 橙色 | 已调整 | 用户在预览页保存段落调整 |
| `EXPORTED` | 灰色 | 已导出 | 成功生成格式化输出文件 |
| `PARSE_FAILED` | 红色 | 解析失败 | 解析过程中抛出异常 |
| `EXPORT_FAILED` | 红色 | 导出失败 | 导出过程中抛出异常（当前版本前端不展示此状态） |
