### 4. 样式规则配置

| 内容 | 说明 |
|------|------|
| 4.1 规则列表 | 进入模板详情 → 规则列表区域；表格各列含义 |

**规则字段详解**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 规则名称 | 文本 | 是 | 如"一级标题""正文""封面标题" |
| 字体名称 | 文本 | 否 | 如"宋体""黑体""Times New Roman" |
| 字号(磅) | 数字 | 否 | 如 12、14、16，Word 常用字号 |
| 加粗 | 开关 | 否 | 开/关 |
| 斜体 | 开关 | 否 | 开/关 |
| 下划线 | 开关 | 否 | 开/关 |
| 删除线 | 开关 | 否 | 开/关 |
| 字体颜色 | 颜色选择器 | 否 | 十六进制颜色值，如 #FF0000 |
| 文本对齐 | 下拉选择 | 否 | 左对齐 / 居中 / 右对齐 / 两端对齐 |
| 首行缩进(字符) | 数字 | 否 | 如 2 表示首行缩进 2 字符 |
| 行距(倍) | 数字 | 否 | 如 1.5 表示 1.5 倍行距 |
| 段前距(磅) | 数字 | 否 | 段落前间距 |
| 段后距(磅) | 数字 | 否 | 段落后间距 |
| 高亮颜色 | 颜色选择器 | 否 | PDF 预览中该规则段落的底色，不设则自动生成 |

### 5. 内容识别引擎配置

| 内容 | 说明 |
|------|------|
| 5.1 引擎配置概述 | 引擎配置 = 正则表达式 + 匹配类型 + 关联规则，决定"哪段文字属于哪种类型" |
| 5.2 匹配类型与优先级 | SPECIAL > COVER > TOC > TITLE > BODY 的匹配优先级说明 |
| 5.3 进入引擎配置页 | 从模板详情页点击「引擎配置」或从左侧菜单进入 |
| 5.4 选择模板 | 下拉选择目标模板 |
| 5.5 新增配置 | 点击「新增配置」→ 填写表单 → 确定 |
| 5.6 编辑配置 | 点击「编辑」→ 修改 → 确定 |
| 5.7 删除配置 | 点击「删除」→ 确认 → 确定 |

**引擎配置字段详解**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 配置名称 | 文本 | 是 | 如"封面匹配""一级标题匹配" |
| 正则表达式 | 文本(多行) | 是 | Java 正则语法，用于匹配段落文本 |
| 匹配类型 | 下拉选择 | 是 | COVER/TOC/TITLE/BODY（详见下方） |
| 标题级别 | 数字 | TITLE时可选 | 1-9，对应 Word 标题级别 |
| 关联样式 | 下拉选择 | 否 | 选择该模板下的规则，匹配后应用对应样式 |
| 排序序号 | 数字 | 是 | 同类型内序号越小越优先匹配 |
| 启用状态 | 开关 | 是 | 停用的配置不参与匹配 |

**匹配类型说明**：

| 类型 | 标签颜色 | 用途 | 典型正则示例 |
|------|---------|------|-------------|
| SPECIAL | 灰色 | 特殊段落精确匹配（由预览调整自动生成） | `^摘要$` 匹配"摘要"段落 |
| COVER | 橙色 | 封面内容匹配 | `论文题目|作者|指导老师` |
| TOC | 蓝色 | 目录行匹配 | `^[\\d.]+\\s+.+` 匹配"1.1 概述" |
| TITLE | 蓝色 | 标题匹配（带级别） | `^第[一二三四五六七八九十]+章` 匹配"第一章" |
| BODY | 绿色 | 正文匹配 | `.*` 匹配所有剩余段落 |

### 6. 文件管理

#### 6.1 文件上传

| 内容 | 说明 |

| 操作步骤 | 选择关联模板（可选）→ 拖拽/选择 .docx 文件 → 点击「开始上传」 |

| 上传后状态 | UPLOADED（蓝色标签） |

**截图标注位**：文件上传页 ×1

#### 6.2 文件列表与操作

**文件状态流转**：

```
UPLOADED → PARSED → ADJUSTED → EXPORTED
                ↓
          PARSE_FAILED
```

| 状态 | 标签颜色 | 说明 |
|------|---------|------|
| UPLOADED | 蓝色 | 已上传，尚未解析 |
| PARSED | 绿色 | 解析成功，可预览 |
| ADJUSTED | 橙色 | 已人工调整段落-规则映射 |
| EXPORTED | 灰色 | 已导出格式化文件 |
| PARSE_FAILED | 红色 | 解析失败，需检查错误信息 |

**操作按钮说明**：

| 按钮 | 可用条件 | 功能 |
|------|---------|------|
| 解析 | 文件已关联模板 | 启动内容识别，生成解析结果 |
| 预览 | 文件已解析 | 进入 PDF 预览与段落调整页 |
| 导出 | 文件已解析/已调整/已导出 | 应用样式规则生成格式化 Word 文件 |
| 下载 | 文件已导出 | 下载格式化后的 .docx 文件 |
| 修改 | 任意状态 | 更改文件关联的模板 |
| 删除 | 任意状态 | 删除文件及所有关联数据（不可恢复） |

**截图标注位**：文件列表页 ×1、修改模板对话框 ×1

#### 6.3 解析预览与调整

| 内容 | 说明 |
|------|------|
| 6.3.1 页面布局 | 顶栏（信息+操作）、左侧 PDF 预览区、右侧图例与调整面板 |
| 6.3.2 PDF 预览 | 高亮叠加层说明、翻页操作、自适应缩放 |
| 6.3.3 样式图例 | 每种规则的底色说明、图例项含义 |
| 6.3.4 段落调整 | 展开段落 → 下拉选择新规则 → 自动保存到引擎配置 |
| 6.3.5 保存调整 | 点击「保存调整」按钮，UNKNOWN 段落自动创建 SPECIAL 配置 |

**段落调整说明**：
- 每个段落显示序号、匹配类型标签、文本预览
- UNKNOWN（红色标签）表示未匹配到任何规则
- 修改规则后，PDF 高亮颜色会随之变化
- 保存调整时，未匹配段落会自动创建 SPECIAL 类型引擎配置

**截图标注位**：预览页全貌 ×1、段落调整展开 ×1、保存确认 ×1

### 7. 完整业务流程示例（论文模板审核）

以高校论文格式审核为场景，展示完整操作流程：

**背景**：学校规定论文必须符合格式规范 — 封面、摘要、目录、各章节标题、正文、参考文献各有指定样式。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 7.1 创建模板 | 新建模板"本科论文模板" | 为论文审核创建专用模板 |
| 7.2 配置规则 | 创建5条规则：封面样式、目录样式、一级标题、二级标题、正文样式 | 分别设置字体、大小、加粗、对齐等 |
| 7.3 配置引擎 | 创建4条配置：COVER匹配封面关键词、TOC匹配目录行、TITLE匹配"第X章"、BODY匹配正文 | 每条配置关联对应规则 |
| 7.4 上传文件 | 上传学生论文 .docx，关联"本科论文模板" | — |
| 7.5 解析文件 | 点击「解析」，系统自动识别各段落类型 | 查看解析状态变为 PARSED |
| 7.6 预览审核 | 点击「预览」，查看 PDF 高亮效果 | 封面=橙色、目录=蓝色、标题=蓝色、正文=绿色 |
| 7.7 手动调整 | 发现某段被标记为 UNKNOWN，展开段落选择正确规则 | 保存后自动创建 SPECIAL 配置 |
| 7.8 导出结果 | 点击「导出」，系统应用样式生成格式化论文 | — |
| 7.9 下载文件 | 点击「下载」，获取格式化后的 .docx | 分发给学生对照修改 |

### 8. 常见问题与故障处理

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 上传失败"仅支持 .docx 格式" | 文件格式不符 | 确认文件扩展名为 .docx |
| 解析失败"未指定解析模板" | 文件未关联模板 | 通过「修改」按钮关联模板后再解析 |
| 解析失败"模板不存在或已停用" | 模板被禁用 | 到模板列表启用该模板 |
| PDF 预览中文显示为空白/乱码 | 中文字体缺失 | 联系管理员安装 SimHei 字体 |
| PDF 高亮位置偏移 | 字符计数偏差 | 点击「保存调整」刷新，或联系管理员 |
| 页面加载空白 | 后端服务未启动 | 确认后端 :8080 和前端 :3000 服务正常 |
| 导出文件样式未生效 | 规则未正确关联 | 检查引擎配置中是否关联了正确的规则 |

### 9. 附录

#### 9.1 界面导航速查

```
首页 (/)                    → 自动跳转模板列表
模板列表 (/templates)       → 模板 CRUD、启停
模板详情 (/templates/:id)   → 规则 CRUD
引擎配置 (/engine-config)   → 引擎配置 CRUD
文件上传 (/file-upload)     → 上传、解析、导出、下载、删除
解析预览 (/parse-preview)   → PDF 预览、段落调整
```

#### 9.2 正则表达式常用示例

| 场景 | 正则表达式 | 说明 |
|------|-----------|------|
| 匹配"摘要"段落 | `^摘要$` | 精确匹配 |
| 匹配"第X章"标题 | `^第[一二三四五六七八九十百]+章` | 中文数字章节 |
| 匹配"1.1 标题"格式 | `^\d+\.\d+\s+.+` | 数字编号标题 |
| 匹配目录行 | `^.+\s*\.{2,}\s*\d+$` | 含省略号和页码 |
| 匹配关键词列表 | `摘要\|Abstract\|关键词\|Keywords` | 多关键词 |
| 匹配所有正文 | `.*` | 通配所有段落 |

#### 9.3 文件状态完整定义

| 状态 | 英文值 | 说明 |
|------|--------|------|
| 已上传 | UPLOADED | 文件已上传，尚未解析 |
| 已解析 | PARSED | 内容识别完成，可预览 |
| 已调整 | ADJUSTED | 人工完成段落-规则映射调整 |
| 已导出 | EXPORTED | 已生成格式化输出文件 |
| 解析失败 | PARSE_FAILED | 解析过程异常（查看 errorMessage） |
| 导出失败 | EXPORT_FAILED | 导出过程异常（查看 errorMessage） |
